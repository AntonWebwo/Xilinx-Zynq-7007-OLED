# OLED Display Tool for Xilinx Zynq (Bitmain Antminer)

[![Platform](https://img.shields.io/badge/Platform-Xilinx%20Zynq%207000-orange)](https://www.xilinx.com/)
[![Hardware](https://img.shields.io/badge/Hardware-Bitmain%20Antminer%20S19-blue)](https://bitmain.com/)
[![Language](https://img.shields.io/badge/Language-C++11-brightgreen)](https://en.cppreference.com/w/cpp/11)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

Легковесная и высокопроизводительная утилита командной строки для управления OLED-дисплеями через шину I2C на платформах **Xilinx Zynq 7000/7007**. Программа разработана специально для контрольных плат майнеров Bitmain (например, Antminer S19), но может быть использована на любых Linux-системах с поддержкой I2C.

> **Inspired by:** [GyverLibs/GyverOLED](https://github.com/GyverLibs/GyverOLED) — легкая и быстрая библиотека для OLED дисплеев.

## 🚀 Особенности

*   **Полная поддержка кириллицы:** Вывод русского текста без искажений.
*   **Гибкая настройка:** Поддержка дисплеев SSD1306 и SSH1106 (разрешения 128x64 и 128x32).
*   **Скриптовая отрисовка:** Мощный DSL (Domain Specific Language) для рисования графики через текстовые файлы.
*   **Тихий режим:** Идеально для интеграции в фоновые процессы и cron-задачи.
*   **Статическая сборка:** Не требует дополнительных библиотек в системе.

## 📦 Установка

В репозитории выложены только скомпилированные статические бинарные файлы. Скачайте версию, соответствующую вашей архитектуре (обычно `arm-linux-gnueabihf` для Zynq).

1.  Скачайте бинарный файл `oled`.
2.  Загрузите его на устройство (через SCP или SD-карту).
3.  Дайте права на выполнение:
    ```bash
    chmod +x oled
    ```

## ⚙️ Использование

### Базовый синтаксис

```bash
./oled [options]
```

### Аргументы командной строки

| Аргумент | Краткий вид | Описание | Пример |
| :--- | :--- | :--- | :--- |
| `--addr` | `-a` | Адрес устройства на шине I2C (HEX) | `-a 0x3C` |
| `--size` | `-s` | Разрешение дисплея | `-s 128x64` |
| `--font` | `-f` | Масштаб шрифта (от 1 до 4) | `-f 2` |
| `--invert` | `-i` | Инвертировать цвета (черный/белый) | `-i` |
| `--data` | `-d` | Путь к файлу со скриптом отрисовки | `-d draw.txt` |
| `--write` | `-w` | Текст для вывода (поддерживает `\n`) | `-w "Hello"` |
| `--bus` | `-b` | Путь к устройству I2C | `-b /dev/i2c-0` |
| `--nocli` | `-n` | Тихий режим (без вывода в терминал) | `-n` |
| `--help` | `-h` | Показать справку | `-h` |

## 💡 Примеры использования

### 1. Простой вывод текста
Вывод приветствия с увеличенным шрифтом:
```bash
sudo ./oled -w "Привет, Zynq!" -f 2
```

### 2. Многострочный текст и инверсия
Использование escape-последовательности `\n` для переноса строки и инверсии цветов:
```bash
sudo ./oled -w "Status: OK\nTemp: 65C" -i -f 1
```

### 3. Работа с конкретным адресом и шиной
Если дисплей подключен к другой шине или имеет нестандартный адрес:
```bash
sudo ./oled -a 0x3D -b /dev/i2c-1 -w "Chain 0 Active"
```

### 4. Тихое выполнение (для скриптов)
Обновление статуса без засорения логов системы:
```bash
sudo ./oled -w "Mining..." -n
```

## 🎨 Скрипты отрисовки (--data)

Программа поддерживает мощный язык скриптов для рисования графики. Создайте текстовый файл (например, `dashboard.txt`) и передайте его через аргумент `-d`.

### Команды скрипта

| Команда | Синтаксис | Описание |
| :--- | :--- | :--- |
| `clear` | `clear` | Очистить весь буфер дисплея |
| `set_pos` | `set_pos <x>, <y>` | Установить курсор текста (в пикселях) |
| `set_scale` | `set_scale <1-4>` | Изменить размер шрифта динамически |
| `write` | `write "Текст"` | Вывести текст (поддерживает `\n`) |
| `rect` | `rect <x1>,<y1>,<x2>,<y2> [mode]` | Нарисовать прямоугольник |
| `line` | `line <x1>,<y1>,<x2>,<y2>` | Нарисовать линию |
| `dot` | `dot <x>, <y>` | Нарисовать точку (пиксель) |
| `circle` | `circle <x>,<y>,<r> [mode]` | Нарисовать окружность |

> **Режимы (mode):** `fill` (заливка, по умолчанию), `stroke` (контур), `clear` (стирание области).
> **Комментарии:** Строки, начинающиеся с `#`, игнорируются.

### Пример 1: Информационная панель майнера

Создайте файл `miner_status.txt`:

```text
# Очистка экрана перед отрисовкой
clear

# Рисуем рамку интерфейса
rect 0, 0, 127, 63, stroke

# Заголовок
set_scale 2
set_pos 10, 5
write "ANTMINER S19"

# Разделительная линия
line 0, 25, 127, 25

# Статус хэш-платы
set_scale 1
set_pos 5, 30
write "Chain 0: 110 TH/s"

# Температура
set_pos 5, 40
write "Temp: 68 C"

# Напряжение
set_pos 5, 50
write "Volt: 14.5 V"
```

Запуск:
```bash
sudo ./oled -d miner_status.txt -s 128x64
```

### Пример 2: Графический логотип и анимация статики

Создайте файл `logo_draw.txt`:

```text
clear

# Рисуем заполненный круг в центре (логотип)
circle 64, 32, 20, fill

# Рисуем контур вокруг него
circle 64, 32, 25, stroke

# Диагональные линии для эффекта "техно"
line 0, 0, 127, 63
line 127, 0, 0, 63

# Текст поверх графики
set_scale 2
set_pos 35, 10
write "POWER"

set_scale 1
set_pos 45, 50
write "ON"
```

### Пример 3: Прогресс-бар (эмуляция)

Создайте файл `progress.txt`:

```text
clear
set_pos 10, 20
write "Loading:"

# Рисуем рамку прогресс-бара
rect 10, 35, 118, 45, stroke

# Заливаем часть бара (эмуляция 50%)
rect 12, 37, 64, 43, fill
```
